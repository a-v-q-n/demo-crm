# demo-crm

CRM de démonstration AVQN — **https://demo-crm.avqn.ch**

Pipeline de deals en quatre colonnes déplaçables à la souris, fiches clients avec timeline
verticale, tableau de bord, et rédaction d'emails assistée par l'API Anthropic puis envoyée par
Resend. Interface conçue pour un écran carré de 1080 × 1080.

Compte de démonstration : `hello@avqn.ch` / `123456`.

[`CLAUDE.md`](./CLAUDE.md).
